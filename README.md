# رفيق المسلم — v1.0.9 (Full Offline)

تطبيق ويب تقدمي (PWA) إسلامي شامل يعمل بالكامل أوفلاين بعد أول فتح.

## جديد في v1.0.9 — تحسينات الوضع النهاري ☀️

- إصلاح لون دائرة عدّاد الأذكار («اضغط الدائرة لكل مرة تقرأ») في أذكار الصباح والمساء والنوم — أصبحت كريمية بحدود ذهبية ونص واضح.
- صفحة مواقيت الصلاة والقبلة: مظهر نهاري كامل (بطاقات بيضاء، عدّ تنازلي ذهبي، بوصلة القبلة بإطار فاتح).
- حاسبة الزكاة: مظهر نهاري كامل.
- التقويم الهجري: مظهر نهاري كامل.
- بطاقات ونوافذ أسماء الله الحسنى: مظهر نهاري كامل.
- إزالة زرّ الليلي/النهاري من صفحة القرآن الكريم — الوضع الآن يُتحكَّم فيه من مركز الإعدادات فقط ويتزامن فورًا مع صفحة القرآن.
- إصلاح البطاقات المكتملة في الأذكار التي كانت تظهر داكنة في الوضع النهاري.


## التشغيل محليًا

التطبيق ملفات ثابتة (Static) — يحتاج فقط سيرفر ثابت بسيط (مطلوب لأن Service Worker لا يعمل من `file://`):

```bash
# من داخل مجلد التطبيق:
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

أو أي استضافة ثابتة (GitHub Pages / Netlify / Cloudflare Pages). ملف `.nojekyll` مضمّن ليعمل مباشرة على GitHub Pages.

> ملاحظة: الصور الافتراضية للمصحف (AVIF) غير مضمّنة في هذه الحزمة، والتطبيق يسحبها تلقائيًا من مرايا ويب ويعمل بدونها.

## الصيانة

- لتعديل قائمة ملفات الكاش: عدّل `STATIC_FILES_RAW` في `sw-rafiq.js` ثم غيّر `VERSION_HASH` لاسم جديد لتفريغ الكاش القديم.
- أداة فحص مرايا المصحف (للمطوّر فقط، غير مضمنة في الحزمة النهائية): كانت في `tools/verify-mirrors.js`.
